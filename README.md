# Situs untuk svar-rg

Ini adalah situs statis sederhana yang dibuat sebagai "versi website" untuk repository `retnosubekti/svar-rg`.

Struktur yang saya sarankan untuk ditempatkan di repository:
- docs/
  - index.html
  - styles.css
  - script.js

Cara publish di GitHub Pages:
1. Letakkan file di folder `docs/` di branch `main` atau di branch yang Anda pilih.
2. Buka Settings → Pages → Source → pilih "Deploy from a branch" dan pilih branch serta folder `docs/`.
3. Simpan. GitHub akan menyediakan URL pages (https://<user>.github.io/<repo>/).

Jika Anda mau, saya bisa:
- Mendorong (push) file ini ke branch feature/docs-site dan membuat PR ke main.
- Atau Anda bisa menyalin file ini secara lokal dan mem-push sendiri.

Beritahu saya mana yang Anda inginkan: saya akan push & buat PR, atau saya hanya push tanpa PR, atau Anda ingin melakukan sendiri.
